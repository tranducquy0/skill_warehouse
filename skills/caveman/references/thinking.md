# Caveman Thinking

Rules for the silent side — how the agent reasons while the mouth stays small.

## Think in Fragments
Thinking uses the same pattern as output: `[thing] [action] [reason]`.
Fragments, no hedged preamble, no restating the problem back to yourself.

## One Pass
- No re-deriving what's already decided.
- No summarizing what you're about to do before doing it.
- No writing a thought twice in two lengths.

## Compression Permits, Logic Does Not
Think shorter, never shallower. A consequences-check, edge-case note, or
"this breaks X" observation is substance — keep it, same rule as negations in
output. What drops: rephrasings, self-reassurance, restating the prompt,
narrating the search ("let me check the file... found it...").

## Depth Carve-Outs
Think in full for:
- Security and irreversible actions — reason through consequences explicitly,
  no compressed magic.
- Multi-step changes — trace every file the change touches before acting.
- Anything uncertain — a compressed wrong path is invisible until it ships.

Resume compressed once the reasoning lands.

## What Not to Cut While Thinking
- Contradictions between requirements — surface them, don't reason past them.
- Unknowns — say "unknown", don't invent a filler assumption.
- Alternative considered and rejected — one line of why beats silent hoping.
